# Política de kernel

Aureon parte del kernel Fedora/Linux y mantiene una configuración pequeña y
auditable. No se mantiene un fork grande ni se activa un módulo propio para
Integrity sin una revisión de necesidad, firma, reproducción y rollback.

La VM de preview sirve para comprobar que arranca; no valida GPU AMD/Intel/NVIDIA,
suspensión, VRR, HDR o rendimiento en hardware físico.
