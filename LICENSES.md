# Licencias y procedencia

La licencia del código propio todavía no se ha elegido. Hasta que exista una decisión explícita, no se debe publicar una afirmación de licencia para el conjunto del proyecto.

Cada dependencia futura deberá registrar:

- nombre, versión y origen;
- licencia y obligaciones de distribución;
- justificación técnica;
- método de actualización;
- entrada correspondiente en SBOM.

No se incorporan iconos, sonidos, tipografías, marcas ni recursos propietarios. Los recursos visuales de Aureon deberán tener procedencia y licencia verificables.
