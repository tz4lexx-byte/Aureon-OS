# Canales y puertas de release

| Canal | Uso | Regla |
| --- | --- | --- |
| Stable | Uso diario | Cambios conservadores y reversibles. |
| Performance | Hardware ya validado | Versiones más recientes con evidencia. |
| Experimental | Pruebas | Nunca se promueve automáticamente. |
| Development | Desarrollo Aureon | Depuración explícita y sin Integrity competitivo. |

Aureon 1.0 exige: instalador probado, rollback, controladores principales,
Game Runtime, Streaming, privacidad, recuperación, pruebas físicas, matriz
pública de compatibilidad y limitaciones conocidas. Una preview QEMU no abre
por sí sola ninguna de esas puertas.
