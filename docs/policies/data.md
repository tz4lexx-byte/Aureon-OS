# Política de datos

Los datos se clasifican como `ESENCIAL`, `RESPALDABLE`, `REGENERABLE`,
`TEMPORAL` o `DESCONOCIDO`. La clasificación canónica está en
[`data-classes.json`](../../packaging/data-classes.json).

Solo `REGENERABLE` y `TEMPORAL` pueden ser candidatos a limpieza automática.
Partidas, mods, prefijos, grabaciones, configuraciones, documentos y cualquier
dato desconocido exigen confirmación antes de borrar o mover.
