# Política de privacidad

Aureon funciona localmente por defecto. No incluye telemetría, cuenta en nube,
identificador permanente, exportación automática de logs ni tráfico de red no
solicitado.

Un diagnóstico se muestra al usuario o se guarda localmente solo cuando el
usuario lo redirige. Para compartirlo se requiere revisar la selección y una
acción manual de nivel D. La preview QEMU no recibe red ni carpetas del host.
