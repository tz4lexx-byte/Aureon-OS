# Contrato de interacción

Las pruebas de molestias verifican que, tras la configuración inicial:

- no hay preguntas rutinarias repetidas;
- no hay popups durante juego o streaming salvo riesgo inmediato de datos;
- no hay reinicios forzados;
- los avisos se agrupan y explican impacto, reinicio y deshacer;
- no existen decisiones destructivas automáticas;
- no se exportan datos sin consentimiento.

La meta es cero interrupciones no urgentes en sesiones de juego/streaming y
cero decisiones de niveles C o D sin el usuario.
