# Laboratorio de compatibilidad

El laboratorio guarda hechos reproducibles, no promesas de compatibilidad. Cada
resultado debe incluir hardware, driver, kernel, runtime, configuración,
resolución, duración, método de medición y limitaciones.

Orden mínimo de pruebas físicas:

1. Aplicación gráfica nativa mínima.
2. Juego Linux de referencia.
3. Juego Windows por Proton.
4. DirectX 9, 11 y 12.
5. Launchers, mandos, audio y pantalla externa.
6. AMD, Intel, NVIDIA y portátil híbrido.
7. Captura local y streaming autorizado.
8. Integrity únicamente después de la revisión correspondiente.

La VM WSLg actual cubre solo el primer escalón funcional. No se presentan sus
resultados como rendimiento de GPU o soporte de hardware.
