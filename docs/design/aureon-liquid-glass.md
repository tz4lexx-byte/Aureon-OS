# Aureon Liquid Glass — principios iniciales

La identidad visual se implementará después de un escritorio funcional. El material de vidrio es una herramienta de jerarquía, no decoración universal.

- Superficies principales: opacas o casi opacas para mantener legibilidad.
- Popovers, paneles y controles flotantes: transparencia discreta con contraste medible.
- Perfiles: Glass Off, Lite, Balanced y Ultra.
- Degradación: reducir blur, ruido, sombras y refracción antes de sacrificar interacción.
- Accesibilidad: temas claro, oscuro y alto contraste; reducir movimiento y transparencia.

No se reutilizan recursos ni medidas propietarias de otros productos. Las decisiones de implementación se documentarán antes de modificar KWin o QML.
